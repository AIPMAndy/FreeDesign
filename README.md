开发时最头疼的问题：
- 🤔 **开发小程序**，去哪找 UI 组件？
- 🤔 **做 React 项目**，有什么现成的设计资源？

**FreeDesign 帮你解决**：按开发场景分类，每个资源都可以**直接拿来用**，丢给 AI 就能按样式开发！

## 🎨 现代设计风格

> 2026 年流行的 UI 设计风格与实现资源

| 风格 | 特点 | 适用场景 | 实现资源 | 预览 |
|------|------|---------|---------|------|
| **Glassmorphism** 🔥 | 毛玻璃效果，透明层次 | 现代 Web 应用、Dashboard | [CSS Glass](https://css.glass) | [示例](https://ui.glass/generator) |
| **Neomorphism** | 柔和阴影，浮雕效果 | 移动应用、简约界面 | [Neumorphism.io](https://neumorphism.io) | [生成器](https://neumorphism.io) |
| **Bento Grid** ⭐ | 卡片网格布局，类似 iOS | SaaS 产品页、Portfolio | [Bento Grids](https://bentogrids.com) | [Aceternity](https://ui.aceternity.com/components/bento-grid) |
| **Brutalism** | 粗犷、高对比度、破格 | 创意类网站、艺术项目 | [Brutalist Websites](https://brutalistwebsites.com) | [示例集](https://brutalistwebsites.com) |
| **Claymorphism** | 粘土质感，柔和 3D | 插画类产品、儿童应用 | [Hype4](https://hype4.academy/tools/claymorphism-generator) | [生成器](https://hype4.academy) |
| **Aurora UI** 🔥 | 极光渐变背景 | Landing Page、Hero 区域 | [Aurora Backgrounds](https://www.aurorauikit.com) | [CodePen](https://codepen.io/tag/aurora) |
| **AI-Native UI** | 对话式、卡片流式 | AI 应用、Chatbot | [ChatGPT UI](https://github.com/mckaywrigley/chatbot-ui) | [v0.dev](https://v0.dev) |
| **Dark Mode First** | 深色优先设计 | 开发工具、代码编辑器 | [Tailwind Dark Mode](https://tailwindcss.com/docs/dark-mode) | [Radix Themes](https://radix-ui.com/themes) |
| **Minimalism** | 极简主义，留白为主 | 企业网站、专业服务 | [Minimal Gallery](https://minimal.gallery) | [Awwwards Minimal](https://awwwards.com/websites/minimal) |
| **Y2K/Retro** | 复古未来主义 | 潮流品牌、创意项目 | [Y2K Aesthetic](https://github.com/topics/y2k) | [Behance Y2K](https://behance.net/search/projects?search=y2k) |

### 风格组合推荐

| 组合 | 描述 | 适用 |
|------|------|------|
| **Glassmorphism + Dark Mode** | 透明玻璃 + 深色背景 | 高端科技产品 |
| **Bento Grid + Minimalism** | 卡片布局 + 极简 | SaaS Landing Page |
| **Aurora + Glassmorphism** | 极光渐变 + 玻璃效果 | 品牌首页 Hero 区域 |
| **Neomorphism + Pastel Colors** | 柔和浮雕 + 马卡龙配色 | 健康/美容类应用 |

## ⚠️ 设计避坑指南

> 常见设计误区与行业特定反模式

### 通用设计误区

#### ❌ 过度使用动画
**问题**: 每个元素都加动画，用户眩晕
**正确做法**: 
- 只在关键交互点添加动画
- 遵循 `prefers-reduced-motion` 媒体查询
- 动画时长: 150-300ms (快速)，300-500ms (正常)

#### ❌ 对比度不足
**问题**: 文字与背景对比度低于 4.5:1
**正确做法**:
- 正文文字对比度 ≥ 4.5:1 (WCAG AA)
- 大标题对比度 ≥ 3:1
- 使用工具: [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker)

#### ❌ 字体过多
**问题**: 一个页面使用 3 种以上字体
**正确做法**:
- 标题字体 + 正文字体 (最多 2 种)
- 通过字重和大小区分层级
- 代码字体单独算

#### ❌ 颜色传递唯一信息
**问题**: 只用颜色区分状态 (色盲用户无法识别)
**正确做法**:
- 颜色 + 图标
- 颜色 + 文字说明
- 颜色 + 形状变化

#### ❌ 点击目标过小
**问题**: 按钮/链接小于 44x44px (移动端)
**正确做法**:
- 移动端最小触摸目标: 44x44px
- 桌面端最小点击目标: 32x32px
- 相邻可点击元素间距 ≥ 8px

---

### 行业特定反模式

#### 🏦 金融/银行类

**❌ 避免**:
- 深色模式作为默认 (信任感不足)
- AI 紫粉渐变 (太过时尚，不够稳重)
- 过度动画 (给人不靠谱感)
- 低对比度设计 (专业度不足)

**✅ 推荐**:
- 浅色模式默认，提供深色切换
- 蓝色系为主，稳重配色
- 清晰的层级和信息架构
- 数据加密标识清晰可见

---

#### 💊 医疗健康类

**❌ 避免**:
- 鲜艳的红色 (引发焦虑)
- 复杂动效 (患者可能身体不适)
- 纯黑背景 (压抑感)
- 过小的文字 (老年人难阅读)

**✅ 推荐**:
- 柔和的蓝绿色系 (平静、信任)
- 大字号、高对比度 (可访问性)
- 简洁明了的信息层级
- 清晰的操作反馈

#### 🛍️ 电商类

**❌ 避免**:
- 加载时间 > 3 秒 (用户流失)
- 弹窗过多 (影响体验)
- 结账流程过长 (> 3 步)
- 不清晰的退换货政策

**✅ 推荐**:
- 图片懒加载 + WebP 格式
- CTA 按钮颜色突出 (高对比度)
- 一键购买流程
- 信任标识清晰 (评价、认证)

#### 🎓 教育/在线学习

**❌ 避免**:
- 自动播放音视频 (打扰学习环境)
- 没有进度保存 (用户焦虑)
- 过于游戏化 (分散注意力)
- 付费墙过早出现

**✅ 推荐**:
- 清晰的学习进度条
- 笔记和书签功能
- 倍速播放控制
- 免费试学部分内容

#### 🍔 餐饮/外卖

### 可访问性检查清单

#### 必须做到 (WCAG AA)

- [ ] 文字对比度 ≥ 4.5:1

## 🎯 使用指南

### 场景 1: 开发现代 SaaS 产品
1. 选择 **shadcn/ui** + **Motion**
2. 参考 [精选技术栈组合](#-精选技术栈组合) 的 "现代 SaaS" 方案
3. 使用科技蓝配色 + Inter 字体
4. 告诉 AI：「用 shadcn/ui 构建一个 SaaS Dashboard，使用 Glassmorphism 风格」

### 场景 2: 开发电商网站
1. 选择技术栈：时尚电商用 **Headless UI**，快消用 **DaisyUI**
2. 参考 [配色方案库](#-配色方案库) 选择配色
3. 查看 [设计避坑指南](#️-设计避坑指南) 的电商注意事项
4. 告诉 AI：「用 Next.js + DaisyUI 实现一个电商首页，活力红配色」

### 场景 3: 开发医疗健康应用
1. 选择 **Material-UI** 或 **Chakra UI**
2. 使用柔和配色 (蓝绿色系)
3. **必读** [设计避坑指南](#️-设计避坑指南) 的医疗类反模式
4. 告诉 AI：「创建一个医疗预约界面，要求高对比度和可访问性」

### 场景 4: 添加微交互动画
1. 选择 **Motion** (原 Framer Motion) 或 **Auto Animate** (通用)
2. 参考 [微交互组件](#-微交互组件) 找灵感
3. 告诉 AI：「用 Motion 实现卡片悬停放大效果，动画 200ms」

### 场景 5: AI 快速原型
1. 使用 **v0.dev** 或 **bolt.new**
2. 描述具体场景 + 风格 + 配色
3. 示例：「创建一个 AI 聊天界面，使用渐变紫配色，流式输出效果」
